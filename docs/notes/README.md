# 开发笔记与调试日志

这个目录放**过程性记录**，按日期命名：`YYYY-MM-DD.md`。

每次调试完花两分钟写四段 —— **只写结论等于没写**：

```markdown
## 2026-09-25 串口一直收到乱码

现象  波特率设成 115200 后，收到的全是 0x00 / 0xFF 交替。
排查  先确认波特率无误，再用万用表量 USB-TTL 与开发板之间有没有公共参考点。
原因  USB-TTL 和开发板没有共地，电平没有共同参考。
改法  补一根 GND 线，问题消失。已同步更新 docs/hardware.md 的接线表。
```

## 值得记的内容

- 现象 → 排查过程 → 根本原因 → 最终改法，四段齐全
- 那些"改了就好了但不知道为什么"的地方，明确标成**待查**，别让它悄悄过去
- 参考手册的具体章节号和页码，方便以后回查
- 一开始想错、后来纠正的地方（错的思路也有价值，下次可能再犯）

## 为什么要记

STM32 的坑大多不是逻辑错误，而是接线、时钟配置、初始化顺序。
这类问题**下次会一模一样地再遇到一遍**，而人不会记得。写下来就是省下次的时间。
